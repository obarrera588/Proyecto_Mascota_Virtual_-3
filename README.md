# Mascota Virtual en C++

Proyecto de **Fundamentos de Programación**.

## Descripción

Mascota Virtual es un juego de consola desarrollado en C++. El jugador adopta una mascota, le pone nombre y debe cuidarla turno a turno: darle de comer, jugar con ella, bañarla, dejarla dormir y darle medicina cuando se enferma.

La mascota tiene necesidades que cambian con el tiempo. Si el jugador la descuida, su salud baja poco a poco hasta que el juego termina. El objetivo es mantenerla viva y feliz el mayor número de días posible.

## Objetivo del proyecto

Aplicar los conceptos vistos en el curso en un programa completo y funcional: variables, condicionales, ciclos, funciones, estructuras, validación de entrada, números aleatorios y manejo de archivos. También buscamos practicar el trabajo en equipo, dividiendo el programa en partes que después se unen en un solo proyecto.

## Funcionalidades principales

- Crear una mascota nueva o cargar una partida guardada.
- Menú de acciones: alimentar, jugar, dormir, bañar, dar medicina, guardar y salir.
- Estadísticas de la mascota: hambre, felicidad, energía, higiene y salud.
- Paso del tiempo: en cada turno la mascota tiene más hambre y se cansa.
- Eventos aleatorios que hacen el juego menos predecible.
- Dibujo de la mascota en ASCII que cambia según su estado de ánimo.
- Pantalla final con los días que sobrevivió la mascota.

## Herramientas

- **Lenguaje:** C++
- **Compilador:** g++ (o el IDE que use cada integrante)
- **Control de versiones:** Git y GitHub

## Forma de trabajo

- Antes de empezar a programar, los tres acordamos los nombres de las funciones y qué recibe y devuelve cada una, para que el código encaje al unirlo.
- Cada integrante trabaja en su propia parte del código para evitar conflictos.
- Cada función debe llevar un comentario corto que explique qué hace.
- Cuando una parte esté lista, otro integrante la prueba y avisa si encuentra errores.
- En la presentación final, cada integrante explica la parte que programó.
