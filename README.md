# Proyecto Mascota Virtual

## Integrantes y responsabilidades

### Carlos: la mascota y sus reglas

Carlos se encarga de definir qué es la mascota y cómo cambia con cada acción.

- Crear la estructura de la mascota con sus datos: nombre, hambre, felicidad, energía, higiene, salud y días vividos.
- Programar las funciones de cada acción: alimentar, jugar, dormir, bañar y dar medicina.
- Definir cuánto sube o baja cada estadística con cada acción.
- Asegurar que las estadísticas siempre se mantengan entre 0 y 100.
- Programar una función que indique si la mascota sigue viva.
- Programar una función que devuelva el estado de ánimo de la mascota (feliz, hambrienta, cansada o enferma).
